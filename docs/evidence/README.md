# Evidence

Things that were run, kept so the claims in the docs can be checked rather than believed.
Every file here is generated by this project — no game data, no third-party binaries.

| File | Produced by | What it shows |
|---|---|---|
| `app-ui.png` | `SummonerRando.Harness --screenshot` (the harness renders the real MainForm headlessly) | the app as the end user sees it: disc in, mode, seed, features, **Build ISO** — and nothing about emulators. Mode shown: *No Enemies*, with its Options pane. |
| `verify-enemy-iso.log` | `python cli.py --verify Summoner-noenemies-ENEMY1.iso --against Summoner.iso -v --log …` | the engine's own check of a built disc: timestamped stages, then every check passing. |
| `verify-enemy-iso.json` | the same run, `--report` | the machine-readable form: sizes, SHA-256s, archive layout, per-check results, and the diff summary. |

## What the verify run proved

```
ok   SYSTEM.CNF names a boot elf            BOOT2 = cdrom0:\SLUS_200.74;1
ok   boot elf is present in the image
ok   disc is a supported Summoner image
ok   script archive found                   0x49086800, 527 entries
ok   every archive lies inside the image    9 archives
ok   same byte length as the source         1232699392 bytes
ok   changes confined to TABLES.VPP         12201 bytes differ, 0 outside the archive
```

That last line is the discipline the whole project rests on: the 527 `TABLES.VPP` entries are
arbitrary slices of one stream, so an edit that lands outside the archive region would corrupt
the disc. It is now a command instead of a hand-run byte diff.

## In-game evidence (numbers, from the headless rig)

These were observed live through PINE and logged in the docs; the runs themselves are not stored
here because each one produces a 1.2 GB disc image.

| Claim | Measurement |
|---|---|
| door destination rewrite redirects a door | two discs differing by one `$Trigger:` string loaded `catacombs` and `Lenele1aa` respectively (`DOOR-REMAP.md` §4.5) |
| monsters are navpoint placements | catacombs: **96 live entities** vanilla → **18** with the "No Enemies" transform (`ENEMIES.md` §4) |
| the door check really runs | patched counters incremented ~2.6×/s while the level was loaded |

## Reproducing any of it

```powershell
# the app screenshot
SummonerRando.Harness.exe --screenshot out.png --state populated --mode peaceful

# the disc check
python cli.py --verify <built.iso> --against <your source.iso> -v --log run.log --report run.json
```
